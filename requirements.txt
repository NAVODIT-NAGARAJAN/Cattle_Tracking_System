IMAGE PREDICTION
POST /api/detections/predict
Content-Type: multipart/form-data

Fields:
image
rfidUid
animalId

Flow:
1. Validate image.
2. Save image.
3. Preprocess image with sharp.
4. Resize to 224x224.
5. Convert to RGB.
6. Normalize to model input.
7. Load best.onnx once and reuse the ONNX session.
8. Run inference with onnxruntime-node.
9. Convert model output to class probabilities.
10. Select highest probability.
11. Return breed and confidence percentage.
12. Return top-3 predictions.
13. Save Detection document.
14. Update Animal breed and breedConfidence.
15. Update Animal latest image/detection/time.
16. Emit detection:created.
17. Return JSON.

DO NOT use placeholder predictions.
